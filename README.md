# Piggy365

Piggy365 — Progressive Web App для накопичення грошей. Користувач створює челендж (мету) і отримує набір карток (наприклад 365), кожна з яких має суму. Ви відмічаєте картки — гроші вважаються відкладеними.

Це повний фронтенд-статичний проєкт (HTML/CSS/Vanilla JS) — підходить для розміщення на GitHub Pages.

Особливості
- Генератор сум з округленням до 50, гарантована рівність суми всіх карток з метою.
- 15-колонкова адаптивна сітка, 365 карток.
- Ripple, flip, scale анімації.
- Пошук суми, фільтри (усі / активні / закриті / сьогодні).
- "Що відкласти сьогодні?" випадкове відкриття картки.
- Статистика: назбирано, залишилось, середній, мін/макс/медіана.
- Календар-heatmap, історія (з можливістю видалення через інтерфейс), досягнення з конфеті.
- Експорт / імпорт JSON (резервна копія).
- Налаштування теми, вібрації, звуків.
- PWA: manifest, service worker, offline page, install prompt, icons.

Технології
- HTML5, CSS3, Vanilla JS (ES2025)
- Ніяких фреймворків чи сторонніх UI-бібліотек.
